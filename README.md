Итоговый вопрос:

Оперативная память намного медленнее процессора поэтому каждое обращение к ней дорого. Процессор загружает данные не по одному элементу, а целой кэш-линией и кладёт её в кэш. При последовательном доступе следующие элементы массива лежат рядом поэтому они уже оказываются в кэше и одна медленная загрузка из RAM обслуживает сразу до 16 обращений

Контрольные вопросы:

1. Зачем процессору нужна кэш-память? 

Процессор работает гораздо быстрее оперативной памяти. Кэш хранит часто используемые данные рядом с процессором чтобы он не ждал медленную RAM

2. Чем кэш отличается от оперативной памяти?

Кэш расположен ближе к процессору он значительно быстрее но намного меньше по объёму и дороже. Оперативная память больше по объёму но медленнее

3. Что такое кэш-линия?

Это минимальный блок данных которым память обменивается с кэшем. Обычно его размер 64 байта. Процессор загружает данные целыми кэш-линиями, а не по одному элементу

4. Почему последовательный доступ к массиву обычно удобнее для кэша, чем доступ с большим шагом?

При последовательном доступе из каждой загруженной кэш-линии используются все 16 элементов поэтому за данными в медленную память приходится ходить редко. При большом шаге из каждой линии нужен только один элемент остальные загружены зря и к памяти приходится обращаться чаще поэтому программа работает дольше

5. Почему результаты эксперимента могут немного отличаться при разных запусках? 

Влияют другие процессы Windows, текущее состояние кэша, частота процессора и размещение массива в памяти. Поэтому нужно запускать программу несколько раз и смотреть на общую закономерность
